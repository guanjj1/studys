### 更新系统包


```shell
sudo apt install nginx -y
```

```shell
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 自动续期证书: 
编辑Cron表以添加新的任务：
```shell
crontab -e

```
在文件末尾加入以下行，这将在每天凌晨两点尝试自动续期证书,
```shell
0 2 * * * /usr/bin/certbot renew --quiet

```
可尝试（这行命令确保了每天的两次运行（上午和下午）之间有一个随机的时间差，以减少对 Let's Encrypt 服务器的并发请求。）
```shell
0 0,12 * * * root python3 -c 'import random; import time; time.sleep(random.random() * 3600)' && certbot renew --quiet
```

Certbot会创建一个定时任务（cron job）来自动续期证书。你可以检查这个定时任务是否存在：
```shell
sudo crontab -l | grep certbot

```
