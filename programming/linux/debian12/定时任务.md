## crontab 命令详解
### 基本用法
编辑当前用户的crontab：

```bash
crontab -e
```
这会打开一个编辑器，你可以在其中添加或修改定时任务。

列出当前用户的crontab：

```bash
crontab -l
```
删除当前用户的crontab：

```bash
crontab -r
```
为指定用户编辑crontab（需要root权限）：

```bash
crontab -u username -e
```
### crontab 文件格式
crontab 文件中的每一行代表一个任务，格式如下：

```text
* * * * * command_to_execute
┬ ┬ ┬ ┬ ┬
│ │ │ │ │
│ │ │ │ └── 星期几 (0 - 6) (0表示星期日)
│ │ │ └──── 月份 (1 - 12)
│ │ └────── 日 (1 - 31)
│ └──────── 小时 (0 - 23)
└────────── 分钟 (0 - 59)
```
### 特殊字符
* *：匹配所有可能的值
* ,：指定多个值（如 1,3,5）
* -：指定范围（如 1-5）
* /：指定间隔频率（如 */2 表示每2个单位）

每天凌晨2点执行备份脚本：

```bash
0 2 * * * /path/to/backup.sh
```
每5分钟检查一次系统状态：

```bash
*/5 * * * * /path/to/check_status.sh
```
每周一上午9点发送报告：

```bash
0 9 * * 1 /path/to/send_report.sh
```
每月1号和15号中午12点清理日志：

```bash
0 12 1,15 * * /path/to/clean_logs.sh
```
