# Docker 版 Jenkins 安装后详细配置指南

&gt; 适用于 2026 年当前的 LTS 版本线（如 2.541.x / 2.568.x）。
&gt; 建议始终使用最新 LTS 并关注安全更新——仅 2026 年就有多起高危 CVE（如路径遍历 CVE-2026-70428、权限提升 CVE-2026-70429 等），及时升级很关键。

---

## 一、启动与首次解锁

### 1. 获取管理员初始密码

```bash
docker logs jenkins        # 日志中会打印密码，形如 a1b2c3d4...
# 或者直接从容器里读：
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
```

### 2. 浏览器访问初始化

打开 `http://&lt;服务器IP&gt;:8080`，粘贴密码进入向导。

&gt; **注意**：确认启动时挂载了数据卷（如 `-v jenkins_home:/var/jenkins_home`），否则容器删除后所有配置和任务会丢失。

## 二、插件安装（国内环境重点）

### 方案 A：安装时改源（推荐）

在「自定义插件」页面前，先把插件源换成国内镜像：
https://mirrors.huaweicloud.com/jenkins/updates/update-center.json

```bash
# 修改更新中心地址为清华镜像(shang)

docker exec jenkins sed -i \
  's#https://updates.jenkins.io/update-center.json#https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json#g' \
  /var/jenkins_home/hudson.model.UpdateCenter.xml
docker restart jenkins
```

### 方案 B：跳过向导手动装插件

```bash
docker exec jenkins java -jar /usr/share/jenkins/jenkins.war \
  --version   # 仅确认 war 位置
```
### 🖥️ 方案 C：通过 Jenkins Web 界面设置（即时生效）
如果你已经启动了 Jenkins，也可以直接通过其管理界面进行修改，无需重启。

进入 Jenkins 仪表盘。

点击 Manage Jenkins -> Manage Plugins。

切换到 Advanced 标签页。

在 Update Site 的 URL 输入框中，填入清华源地址：https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json，然后点击 Submit 保存即可。



常用必装插件（Manage Jenkins → Plugins → Available plugins）：

| 插件 | 用途 |
|---|---|
| **Localization: Chinese (Simplified)** | 简体中文界面 |
| **Git** / GitHub / GitLab / Gitee | 代码仓库集成 |
| **Pipeline** / Declarative Pipeline | 流水线（核心，默认已装） |
| **Credentials Binding** | 凭据注入流水线 |
| **SSH Build Agents** | SSH 方式连接 Agent 节点 |
| **Docker Pipeline** / Docker plugin | 流水线中构建 Docker 镜像 |
| **Kubernetes** | K8s 动态 Agent（如在 K8s 环境） |
| **Blue Ocean** | 现代化流水线 UI（可选） |
| **SonarQube Scanner** | 代码质量扫描 |
| **Ansible** / **Publish Over SSH** | 部署到远程服务器 |
| **Timestamper** / **AnsiColor** / **Build Timeout** | 日志增强 |

## 三、创建管理员账号与基础设置

1. 初始化向导创建第一个管理员用户（建议不用默认 admin）。
2. 进入 **Manage Jenkins → System**（系统配置）：
   - **Jenkins URL**：填实际访问地址，如 `http://192.168.1.10:8080/`
   - **系统管理员邮件地址**：如 `jenkins@example.com`
   - **时区**：追加 JVM 参数（见下方「常见问题」）。

---

## 四、全局工具配置（Global Tool Configuration）

路径：**Manage Jenkins → Tools**（全局工具配置），这是构建能跑起来的关键。

### 1. JDK（Jenkins 镜像内自带 17/21，通常直接选自动安装）

- 推荐直接使用镜像内置 JDK：`/opt/java/openjdk`
- 如需其他版本 → Add JDK → 选「Install from adoptium.net」自动安装 21

### 2. Git

- 容器内已自带 git，填名称 `Default`，Path 留空或 `/usr/bin/git`

### 3. Maven（容器默认没有，需要配置）

- Add Maven → 名称 `maven3` → 选「Install from Apache」→ 版本选 3.9.x → 勾选自动安装
- 或用挂载方式使用宿主机/共享目录中的 Maven

### 4. NodeJS（前端项目需要）

- 安装 **NodeJS Plugin** 后在此配置自动安装 Node 20/22

### 5. Docker（容器内调用 Docker）

在启动容器时挂载宿主机的 docker socket：

```bash
docker run -d \
  -p 8080:8080 -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --name jenkins jenkins/jenkins:lts
```

并给容器内用户授权：

```bash
docker exec -u root jenkins apt-get update && apt-get install -y docker-cli
docker exec -u root jenkins usermod -aG docker jenkins
docker restart jenkins
```

## 五、凭据管理（Credentials）

路径：**Manage Jenkins → Credentials → System → Global credentials**

建议配置：

| 凭据类型 | 用途 |
|---|---|
| Username with password | Git 仓库账号密码 |
| SSH Username with private key | Git SSH 私钥、登录部署服务器 |
| Secret text | Access Token（GitHub/Gitee Token、SonarQube Token） |
| Secret file | kubeconfig、证书文件 |

&gt; 凭据创建后在 Pipeline 里用 `credentialsId` 引用，通过 **Credentials Binding** 插件安全注入，避免明文写密码。

## 六、安全配置（Manage Jenkins → Security）

### 1. 认证与安全域（Security Realm）

- 小规模：Jenkins 专有用户数据库
- 企业环境：LDAP，或 GitHub/GitLab OAuth（装对应插件）

### 2. 授权策略（Authorization）

- **推荐 Matrix-based security**（装 Matrix Authorization Strategy 插件）：
  - 开发者：`Job/Read` + `Job/Build`（不要给 Overall/Administer）
  - 管理员组：全部权限
- 或简单的「登录用户可以做任何事 / 匿名用户只读」

### 3. 其他安全项（保持默认开启）

- CSRF Protection ✅
- Agent → Controller Access Control ✅
- 不让 Agent 节点的工作目录暴露敏感凭据

## 七、Agent 节点配置（分布式构建）

控制器（Controller）**不要跑构建任务**，设置控制器执行器为 0，用 Agent 跑任务：

1. **Manage Jenkins → Nodes → Built-in Node** → Number of executors 改为 `0`
2. **New Node** → 类型选 **Permanent Agent**（固定节点）或 SSH Agent：
   - Remote root directory：`/home/jenkins/agent`
   - Labels：`linux docker maven`（用于 Pipeline 中 `agent { label '...' }` 调度）
   - Launch method：SSH（填 IP + 凭据）
   - 可用性：Keep this agent online as much as possible

## 八、常用优化项

### 1. JVM 参数与时区（重要）

修改容器启动命令，设置堆内存和时区：

```bash
docker run -d \
  -p 8080:8080 -p 50000:50000 \
  -e JAVA_OPTS="-Xms2g -Xmx4g -Duser.timezone=Asia/Shanghai" \
  -e TZ=Asia/Shanghai \
  -v jenkins_home:/var/jenkins_home \
  --name jenkins jenkins/jenkins:lts
```

### 2. 邮件通知（可选）

System 配置里配置 SMTP（QQ邮箱/163 邮箱需开启 SMTP 授权码），配合 **Email Extension** 插件发送构建通知。

### 3. 备份

备份 `jenkins_home` 卷即可，重点目录：

- `config.xml`、`jobs/`、`users/`、`credentials.xml`、`plugins/`
- 可配合 **ThinBackup** 插件做定时备份

## 九、验证：跑一个最小 Pipeline

新建 Item → Pipeline 任务，粘贴：

```groovy
pipeline {
    agent any
    stages {
        stage('Hello') {
            steps {
                sh 'java -version && git --version && mvn -v'
                echo "构建成功: ${env.BUILD_NUMBER}"
            }
        }
    }
}
```

能正常输出 JDK、Git、Maven 版本，说明全局工具配置完成。

## 十、常见问题速查

| 问题 | 解决 |
|---|---|
| 插件安装慢/失败 | 换清华/阿里云镜像源（见第二部分） |
| 界面时间不对 | `-Duser.timezone=Asia/Shanghai` + 系统设置里改时区显示 |
| `mvn: command not found` | 没配 Maven 自动安装，去全局工具配置补 |
| 构建时报 docker 权限错误 | 挂载 docker.sock + `usermod -aG docker jenkins` |
| Agent 连不上 50000 端口 | 确认防火墙放行 50000（JNLP 端口），容器启动时映射了 `-p 50000:50000` |
| 忘记 admin 密码 | 进容器执行：`java -jar /usr/share/jenkins/jenkins-cli.jar` 或直接改 `users/*/config.xml` 删除 passwordHash 字段后重启 |
