### 🚀 步骤一：先创建项目目录和数据目录：
```shell
sudo mkdir -p /opt/gitlab
cd /opt/gitlab

```
### 🚀 步骤二：
```yaml
version: '3.8'

services:
  gitlab:
    image: gitlab/gitlab-ce:17.4.6-ce.0   # 强烈建议固定版本，避免意外升级
    container_name: gitlab
    restart: always
    hostname: gitlab.example.com
    environment:
      GITLAB_OMNIBUS_CONFIG: |
        # 对外访问地址，这里决定你克隆代码时显示的仓库地址前缀
        external_url 'http://gitlab.example.com:8929'
        #克隆仓库时 GitLab 会正确提示 SSH 地址
        gitlab_rails['gitlab_shell_ssh_port'] = 2222

        # 时区设置，默认是UTC，日志和界面时间会差8小时
        gitlab_rails['time_zone'] = 'Asia/Shanghai'

        # 关闭一些用不上的组件，节省内存 性能监控 用户量大最好打开默认不设置
        #GitLab 从 16.3 版本开始，已经彻底移除了内置的 Grafana 组件
        grafana['enable'] = false
        prometheus['enable'] = false

        # 备份保留时间，这里保留7天
        gitlab_rails['backup_keep_time'] = 604800
    ports:
      # SSH端口映射，SSH协议克隆代码用 GITLAB_OMNIBUS_CONFIG gitlab_rails['gitlab_shell_ssh_port']
      - "2222:22"
      # HTTP端口映射 GITLAB_OMNIBUS_CONFIG external_url端口
      - "8929:8929"
      # HTTPS端口，如不需要可注释
      - "443:443"
    volumes:
      # 配置目录
      - /opt/gitlab/config:/etc/gitlab
      # 数据目录（仓库、数据库）
      - /opt/gitlab/data:/var/opt/gitlab
      # 日志目录
      - /opt/gitlab/logs:/var/log/gitlab
    shm_size: '256m'

```

### 🚀 步骤三：启动与初始化

配置完成后，在 `/srv/gitlab` 目录下执行以下命令启动服务：

```bash
docker-compose up -d
```

容器首次启动需要 **5-10 分钟**完成内部组件的初始化。可以通过以下命令实时查看启动日志，等待出现 `gitlab Reconfigured!` 等字样即表示启动完成：

```bash
docker logs -f gitlab
```

启动完成后，获取自动生成的 root 初始密码：

```bash
docker exec -it gitlab grep 'Password:' /etc/gitlab/initial_root_password
```

> **注意**：该密码文件在容器启动 **24 小时后**会被自动删除，请及时登录并修改密码。

最后，在浏览器中访问你设置的 `external_url` 地址（如 `https://gitlab.example.com`），使用用户名 `root` 和上述密码登录即可。

### 💡 进阶配置提示

- **配置 HTTPS**：若需启用 HTTPS，可在 `GITLAB_OMNIBUS_CONFIG` 中添加 `letsencrypt['enable'] = true` 并配置邮箱，GitLab 将自动申请和续期 Let's Encrypt 证书（需域名已解析到本机且 80/443 端口可访问）。
- **配置邮件通知**：如需 GitLab 发送邮件（如注册确认、通知），可在 `GITLAB_OMNIBUS_CONFIG` 中配置 SMTP 参数，例如：
  ```yaml
  gitlab_rails['smtp_enable'] = true
  gitlab_rails['smtp_address'] = "smtp.example.com"
  gitlab_rails['smtp_port'] = 587
  gitlab_rails['smtp_user_name'] = "your_email@example.com"
  gitlab_rails['smtp_password'] = "your_password"
  ```
- **数据备份与恢复**：可在宿主机执行备份命令，备份文件会保存在挂载的 `data` 目录中：
  ```bash
  docker exec -it gitlab gitlab-backup create
  ```
