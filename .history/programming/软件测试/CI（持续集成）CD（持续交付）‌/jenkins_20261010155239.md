```shell
docker run \
  -u root \
  --rm \
  -d \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins-data:/var/jenkins_home \
  -v /var/run/docker.sock:/var/run/docker.sock \
  jenkinsci/blueocean
```

### 2.

`jenkinsci/blueocean` 这个镜像已经被官方**废弃且不再维护**了，所以拉取失败是预期结果。

### 为什么拉取会失败？
`jenkinsci/blueocean` 镜像早在2022年就已停止更新，官方推荐迁移到标准的 `jenkins/jenkins` 镜像。这个旧镜像存在以下严重问题：
*   **系统过时**：基于已停止维护的 Alpine 3.16.2 系统，且仅支持 amd64 平台。
*   **安全风险**：内置的 Jenkins 版本为 2.346.3，存在已知的**严重安全漏洞**。

### 推荐的替代方案
现在官方推荐的方案是使用标准的 `jenkins/jenkins` 镜像，再按需安装插件。这个镜像会持续更新，安全性和兼容性都更有保障。

**1. 启动标准 Jenkins 容器**
使用以下命令启动一个最新的 Jenkins LTS 容器（以 `jdk11` 版本为例）：
```bash
docker run -d --name jenkins -p 8080:8080 -p 50000:50000 --restart=on-failure jenkins/jenkins:lts-jdk11
```
> **注意**：`jenkins/jenkins` 镜像**不预装** Blue Ocean 插件，需要启动后手动安装。

**2. 安装替代插件（推荐）**
由于 Blue Ocean 本身也已于2026年7月停止更新，官方建议考虑使用 **Pipeline Graph View** 插件，它被视为 Blue Ocean 的继任者，可以在标准的 Jenkins UI 中提供现代化的流水线可视化。

**3. 手动安装 Blue Ocean 插件（可选）**
如果你仍想使用 Blue Ocean，可以在启动容器后，通过 Jenkins 的 Web 界面手动安装：
*   进入 **Manage Jenkins** -> **Plugins**。
*   在 **Available** 选项卡中搜索 `blue ocean`。
*   勾选 **Blue Ocean** 插件并安装即可。

### 数据迁移注意事项
如果你有基于旧镜像的现有实例，直接切换镜像可能无法启动。建议在迁移前，备份好 `/var/jenkins_home` 目录下的数据，并在新容器中通过挂载卷的方式重新使用这些数据。
