# Jenkins (`jenkins/jenkins`) Docker 安装使用完整教程

## 一、背景与镜像选择

### 1.1 为什么不再使用 `jenkinsci/blueocean`

`jenkinsci/blueocean` 镜像已停止维护，基于 Alpine 3.16.2 旧系统，内置 Jenkins 2.346.3，存在未修复的严重安全漏洞。官方推荐迁移到标准的 `jenkins/jenkins` 镜像。

### 1.2 `jenkins/jenkins` 镜像标签选择

| 标签                        | 适用场景     | 说明                           |
| --------------------------- | ------------ | ------------------------------ |
| `jenkins/jenkins:lts`       | 通用生产     | 最新 LTS 版本                  |
| `jenkins/jenkins:lts-jdk17` | **推荐生产** | LTS + JDK 17，兼容性与性能平衡 |
| `jenkins/jenkins:lts-jdk21` | 新项目       | LTS + JDK 21，支持最新特性     |
| `jenkins/jenkins:latest`    | 仅测试/尝鲜  | Weekly 版本，稳定性风险高      |

生产环境优先选择 LTS 版本，每 12 周发布一次，官方提供至少 1 年的安全更新与 bug 修复。**推荐使用 `jenkins/jenkins:lts-jdk17`**，因为 Jenkins 2.479.1 起已要求 Java 17，Java 11 镜像已退役。

## 二、安装部署

### 2.1 方式一：Docker Run（快速启动）

**步骤 1：拉取镜像**

```bash
docker pull jenkins/jenkins:lts-jdk17
```

**步骤 2：创建数据目录并设置权限**

容器内 Jenkins 默认以 uid=1000 运行，需提前修正宿主机目录权限：

```bash
sudo mkdir -p /srv/jenkins_home
sudo chown -R 1000:1000 /srv/jenkins_home
```

**步骤 3：启动容器**

```bash
docker run -d --name jenkins \
  -p 8080:8080 -p 50000:50000 \
  -v /srv/jenkins_home:/var/jenkins_home \
  -e TZ=Asia/Shanghai \
  -e JAVA_OPTS="-Duser.timezone=Asia/Shanghai -Xmx2g -Xms512m" \
  --restart unless-stopped \
  jenkins/jenkins:lts-jdk17
```

> **端口说明**：8080 为 Web UI，50000 为 Agent 通信端口。
> **数据持久化**：`-v /srv/jenkins_home:/var/jenkins_home` 将数据映射到宿主机，避免容器重建导致数据丢失。

### 2.2 方式二：Docker Compose（推荐，便于管理）

创建 `docker-compose.yml`：

```yaml
version: "3.8"
services:
  jenkins:
    image: jenkins/jenkins:lts-jdk17
    container_name: jenkins
    restart: unless-stopped
    ports:
      - "8080:8080"
      - "50000:50000"
    volumes:
      - jenkins_home:/var/jenkins_home
      - /var/run/docker.sock:/var/run/docker.sock  # 可选：容器内调用宿主机 Docker
    environment:
      - TZ=Asia/Shanghai
      - JAVA_OPTS=-Duser.timezone=Asia/Shanghai -Xmx2g -Xms512m

volumes:
  jenkins_home:
```

启动：

```bash
docker compose up -d
```

如需在 Jenkins 容器内构建 Docker 镜像，可挂载 Docker 套接字。

## 三、初始化配置

### 3.1 获取初始管理员密码

Jenkins 首次启动会生成临时管理员密码，通过以下命令获取：

```bash
docker exec jenkins cat /var/jenkins_home/secrets/initialAdminPassword
```

也可通过日志获取：

```bash
docker logs jenkins 2>&1 | grep "initialAdminPassword"
```

### 3.2 解锁与初始化向导

1. 浏览器访问 `http://<服务器IP>:8080`
2. 在 **Unlock Jenkins** 页面粘贴初始密码，点击 **Continue**
3. 选择 **Install suggested plugins**（安装推荐插件），等待完成
4. 在 **Create First Admin User** 页面填写管理员用户名、密码、邮箱等信息
5. 确认 Jenkins URL，完成初始化

> **提示**：若跳过了创建管理员用户步骤，初始密码将作为默认管理员账户（用户名 `admin`）的密码。

## 四、插件安装

### 4.1 配置国内插件镜像（重要）

默认插件源在国内下载极慢，建议先更换为清华镜像。进入 **Manage Jenkins → Manage Plugins → Advanced**，将 **Update Site** 修改为：

```
https://mirrors.tuna.tsinghua.edu.cn/jenkins/updates/update-center.json
```

保存后重启 Jenkins 容器使配置生效。

### 4.2 安装 Pipeline Graph View（推荐替代 Blue Ocean）

由于 Blue Ocean 已于 2026 年 7 月停止更新，官方推荐 **Pipeline Graph View** 作为替代方案，它能在标准 Jenkins UI 中提供现代化的流水线可视化。

**安装步骤**：

1. 进入 **Manage Jenkins → Plugins**
2. 切换到 **Available** 选项卡
3. 搜索 `Pipeline Graph View`
4. 勾选插件并点击 **Install without restart**

**启用视图**：

安装后进入 **Manage Jenkins → Appearance**，在 **Pipeline Graph View** 区域勾选 **Show in job page** 或 **Show in build page**，即可在作业页面或构建页面直接查看图形化流水线。

### 4.3 安装 Blue Ocean（可选）

若仍需 Blue Ocean，可在插件管理中搜索 `blue ocean`，勾选 **Blue Ocean** 插件包并安装。安装后侧边栏会出现 **Open Blue Ocean** 入口。

## 五、从旧镜像迁移数据

如果你有基于 `jenkinsci/blueocean` 的现有实例，可参照以下步骤迁移：

### 5.1 备份旧数据

```bash
# 方法一：从旧容器拷贝
docker cp <旧容器名>:/var/jenkins_home /backup/jenkins_home_backup

# 方法二：若使用命名卷
docker run --rm -v jenkins_old:/var/jenkins_home -v $(pwd):/backup \
  alpine tar czf /backup/jenkins_home.tar.gz -C /var/jenkins_home .
```

### 5.2 恢复数据到新容器

```bash
# 停止新容器
docker stop jenkins

# 清空新数据目录并恢复
sudo rm -rf /srv/jenkins_home/*
sudo cp -a /backup/jenkins_home_backup/. /srv/jenkins_home/
sudo chown -R 1000:1000 /srv/jenkins_home

# 重启
docker start jenkins
```

> **关键**：凭据文件（`credentials.xml`）依赖 `secrets/secret.key`，必须一并迁移，否则凭据将失效。建议迁移前检查插件兼容性，旧镜像（Jenkins 2.346.3）的插件可能不兼容新版本。

## 六、性能调优

### 6.1 JVM 内存参数

通过 `JAVA_OPTS` 环境变量调整 JVM 堆内存：

```bash
-e JAVA_OPTS="-Xms2g -Xmx2g -XX:MaxMetaspaceSize=512m -Dfile.encoding=UTF-8"
```

建议将 `-Xms` 与 `-Xmx` 设为相同值（通常为物理内存的 1/2），避免运行期扩缩堆带来的性能抖动。

对于 Java 17+ 环境，官方推荐使用百分比方式配置：

```bash
-e JAVA_OPTS="-XX:+UseG1GC -XX:MaxRAMPercentage=60.0 -XX:InitialRAMPercentage=20.0"
```

### 6.2 时区设置

```bash
-e TZ=Asia/Shanghai
-e JAVA_OPTS="-Duser.timezone=Asia/Shanghai"
```

## 八、常见问题

**Q：容器启动后立即退出？**
A：检查数据目录权限是否为 uid=1000。使用 `sudo chown -R 1000:1000 /srv/jenkins_home` 修正。

**Q：插件下载极慢或失败？**
A：更换插件更新站点为清华镜像（见 4.1 节），或在宿主机 `/srv/jenkins_home/updates/default.json` 中替换下载地址。

**Q：如何升级 Jenkins？**
A：拉取新标签镜像，停止旧容器（保留数据卷），用相同挂载参数启动新容器即可。升级前务必备份 `jenkins_home`。

**Q：能否在容器内构建 Docker 镜像？**
A：可以。启动时挂载 `-v /var/run/docker.sock:/var/run/docker.sock`，或使用 Docker-in-Docker 方案。
