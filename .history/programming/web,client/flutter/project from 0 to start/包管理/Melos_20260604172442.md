### 安装与初始化

#### 安装 Melos

```shell
dart pub global activate melos
```
如果用FVM管理Flutter版本，则是：

```shell
fvm dart pub global activate melos

# 切换 Flutter 版本后，重新安装 global 包
fvm use 3.29.0
fvm dart pub global activate melos

```
后面执行命令需要：
```shell
fvm dart pub global run melos bootstrap
fvm dart pub global run

```
初始化 Melos 工作区
```shell
mkdir hm-aimusic
cd hm-aimusic

```
运行以下命令初始化工作区：
```shell
melos init

```
系统会提示你输入项目名称（例如 hm_aimusic）和描述。完成后，根目录下会生成一个 melos.yaml 文件和一个基础的 pubspec.yaml。

打开 melos.yaml，我们需要定义包的搜索路径。编辑文件如下：
```yaml
name: hm_aimusic

packages:
  - apps/**
  - packages/**

```
接下来，我们在 apps 目录下创建一个 Flutter 应用程序。由于我们只需要支持 Android、iOS 和 Web，可以通过指定平台参数来减少不必要的文件生成。

在终端中执行以下命令：
```shell
flutter create -t app --platforms=android,ios,web apps/main_app

```
创建完成后，你的目录结构应如下所示：

```text
hm-aimusic/
├── apps/
│   └── main_app/      # 包含 android, ios, web 文件夹
├── melos.yaml
└── pubspec.yaml

```
模块化开发的核心在于将功能拆分为独立的包。我们在 packages 目录下创建一个名为 core 的基础库。

执行以下命令：
```shell
flutter create --template=package packages/core

```
此时，目录结构更新为：

```text
hm-aimusic/
├── apps/
│   └── main_app/
├── packages/
│   └── core/          # 包含 lib 文件夹
├── melos.yaml
└── pubspec.yaml


```
为了让 main_app 能够使用 core 包中的代码，我们需要在 main_app 的 pubspec.yaml 中添加依赖。

打开 apps/main_app/pubspec.yaml，在 dependencies 部分添加：
```yaml
dependencies:
  flutter:
    sdk: flutter
  core: # 引用本地包
    path: ../../packages/core

```
依赖配置完成后，我们需要让 Melos 处理这些依赖关系并链接包。

在项目根目录下运行：
```shell
melos bootstrap

```
该命令会：

扫描 melos.yaml 中定义的所有包。
安装每个包的依赖。
将本地包（如 core）链接到引用它们的应用（如 main_app）。
